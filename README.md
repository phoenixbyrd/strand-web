# Strand — web build

The web version of **Strand**, the offline DNA report app.

**Privacy: all DNA processing happens in your browser.** Upload your consumer raw-genotype file (23andMe, AncestryDNA, etc.) and every calculation — traits, health markers, pharmacogenomics, ancestry, Neanderthal estimate, chromosome painting — runs locally in client-side JavaScript. Nothing is uploaded anywhere; there is no server receiving your genome. Your file is cached only in your own browser's IndexedDB so a refresh doesn't lose your report.

This repo hosts the static build served via GitHub Pages. The app source lives in the Strand project (Next.js static export, MIT-licensed).

*Strand reports are informational and educational — not medical advice, not a diagnosis. Talk to your doctor or pharmacist about any health or medication decisions.*
